# Space Management System

Java console final project managing missions, spacecraft, resources and research projects.

**Portfolio:** [Carl Renz Colico](https://github.com/renzkie8) · **Year / Section:** Year 2 — BSCS 2-A

## Methodology

Model domain entities with encapsulation, inheritance and polymorphism, then connect management operations through a console menu.

## Getting started

With a JDK installed, run `javac -d build src/com/example/mainspacers/*.java`, then `java -cp build com.example.mainspacers.MainSpace`. This documents the expected entry point; compilation was not run in the portfolio audit because no JDK was available.
